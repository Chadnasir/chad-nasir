# Chad Nasir — Land Advisory

Hand-built single-page site for **Chad Nasir**, Land Specialist with eXp Commercial
(Anaheim, California · CA License #02086093).

- Light editorial design, oversized Archivo typography, IBM Plex Mono meta labels
- MotionSites-grade motion choreography: staged hero reveal, letter-scramble titles,
  lerped smooth scroll, magnetic CTAs, scroll-linked manifesto illumination,
  expanding case rows with full-screen lightbox, live Pacific clock
- Zero dependencies, zero build step — pure HTML/CSS/vanilla JS
- Assets in `assets/` are custom-generated aerial/land photography

## Run locally

```bash
python3 -m http.server 8000
# open http://127.0.0.1:8000/
```

## Deploy

Pushing `main` publishes via GitHub Pages.
